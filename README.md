# SIGNAL 개발·테스트 작업본

한국 주식·국내 ETF 기술적 분석 앱입니다. **정식 사이트는 변경하거나 배포하지 않았습니다.** 자동 주문은 실행하지 않습니다.

## 소스와 변경 범위

2026-11-14에 사용자가 제공한 index.html, CODEX_INSTRUCTIONS.md, README.md 및 api/*.js 7개를 기준으로 작업했습니다. Git 원격은 커밋이 없는 빈 저장소였으므로 운영 코드와 Git 이력을 대조하지 못했습니다. 원본 README에 따르면 breaking-news.js는 재구성본이며 원본 동일성이 보장되지 않습니다. 서버 환경변수와 Vercel 설정·인증은 제공되지 않았습니다.

UI/네트워크 처리는 app.js, 테스트 가능한 계산은 analysis.js로 분리했습니다. index.html과 API를 함께 배포해야 합니다. 실제 시세를 대체하는 데모 데이터를 앱에 넣지 않았습니다. 합성 데이터는 tests/에만 있습니다.

## 설치와 실행

Node.js 24.5 이상(검증: 24.22.1), npm, Chromium이 필요합니다. 클라우드에는 /usr/bin/chromium이 있습니다. 다른 환경은 CHROMIUM_PATH로 Chromium 실행 파일을 지정합니다.

```sh
cd /workspace/signal
npm ci --cache /workspace/.npm-cache --ignore-scripts
npm start
```

개발 서버는 127.0.0.1:4173에서 기존 Vercel 서버리스 함수를 로컬 실행합니다. 프로덕션 API로 우회하지 않습니다. 원격 데이터에는 외부 네트워크 접근이 필요합니다. 별도 빌드 단계는 없으며 브라우저가 JS를 직접 실행합니다.

```sh
npm test
```

Node 계산·API 테스트와 Playwright 데스크톱/휴대폰 테스트를 실행합니다. 테스트 러너가 서버를 시작하고 종료합니다. 이미 서버가 있으면 재사용합니다. 브라우저 테스트는 실제 시세가 아닌 명시적인 합성 OHLC 데이터를 사용합니다.

## 판단 규칙

- 선택 시점까지의 완료된 봉 전체로 MA20, MA60, MACD(12,26,9), Wilder RSI(14)를 계산합니다. 110봉 제한은 화면에만 적용합니다.
- 최소 60봉 미만이면 회색 판단 보류입니다. 과거 슬라이더 첫 지점도 선택 가능하며 목표/위험 수치는 숨깁니다.
- 매수 관심 구간은 **선택 봉 직전 20봉 종가 평균**을 중심으로 잡습니다. 폭은 평균의 2.5%와 직전 20봉 종가 범위/4 중 큰 값입니다. 하단=평균−폭, 상단=평균+폭×0.25입니다. 현재 가격에 맞춰 구간을 끌어내리지 않습니다.
- 초록 매수 검토: 구간 안 + 종가가 MA20/MA60 이상 + MA20 상승 + MACD가 신호선 위이면서 직전보다 상승 + RSI 50 이상 70 미만을 모두 충족.
- 빨강 매수 주의: 구간 하단 이탈, RSI 70 이상, 또는 MA20/MA60 아래이고 MACD가 신호선 아래. 나머지는 노랑 관망입니다. 수익률 개선을 검증한 전략이라는 뜻은 아닙니다.
- 목표=직전 20봉 종가 고점과 현재 종가+폭 중 큰 값. 위험=직전 20봉 종가 저점, MA60, 현재 종가−폭 중 작은 값(0 이상). 관심 구간 중간값은 기술적 참고값이며 적정가치 평가가 아닙니다.
- 일봉은 서울 15:30 이후만 완료로 봅니다. 5분 원본은 시작시각+5분 이후, 10/30/60분 집계는 해당 묶음 종료 후만 사용합니다. 분봉 시각은 서울 시간입니다.
- 거래소 휴장일 달력이 없어 주봉은 다음 월요일 00:00, 월봉은 다음 달 1일 00:00 서울 시간 이후만 포함하는 보수적인 규칙입니다. 주말에도 이번 주 마지막 봉이 잠시 제외될 수 있습니다. 첫 부분 기간은 제공된 데이터만 집계합니다.
- 일봉 요청은 1600개로 늘렸지만 제공처가 반환하는 기간은 보장할 수 없습니다. 신규 종목·월봉 등에서 60봉을 확보하지 못하면 판단하지 않습니다.
- 수급·뉴스·시장 비교·현재가 패널은 최신 자료이며 과거 기술적 판단과 별개라고 표시합니다. 과거 판단에 이 자료를 섞지 않습니다. 조정주가의 과거 시점별 원본 이력을 보유하지 않으므로 엄밀한 시점별 백테스트를 제공하지 않습니다.

## 네트워크와 한계

필요 도메인: fchart.stock.naver.com, finance.naver.com, m.stock.naver.com, query1.finance.yahoo.com, news.google.com, raw.githubusercontent.com, registry.npmjs.org. API 키는 현재 코드에서 요구하지 않습니다. 인증 값은 소스에 넣지 않습니다.

현재 클라우드에서는 네이버·Yahoo·Google 뉴스 요청이 프록시 CONNECT 403으로 차단됐습니다. 필요한 도메인을 환경 설정 초안에 저장했지만 실행 환경 적용과 실제 시세 검증은 미완료입니다. 환경 설정에서 변경을 검토·저장하고 클라우드 환경을 게시한 후 실제 종목 조회를 다시 확인해야 합니다. 클라우드 환경 게시와 SIGNAL 정식 사이트 배포는 별개의 작업입니다.

naver-quote.js는 원본부터 503을 반환하는 미구현 API입니다. 다른 시세를 실시간 체결가로 가장하지 않습니다. 수급 일부 실패, 뉴스 출처 일부 실패, 시장 비교 실패를 각각 표시합니다. 외부 원본의 가용성·신뢰성은 합성 테스트로 보장되지 않습니다.

## 미리보기 배포와 정식 반영

Vercel 프로젝트에서 **Preview 환경**으로만 배포한 뒤 실제 삼성전자(005930), KODEX 200(069500), TIGER 200(102110)을 확인해야 합니다. Vercel 인증이 제공되지 않아 이번 작업에서는 외부 미리보기 배포를 하지 못했습니다. 프로젝트 ID만으로는 배포할 수 없습니다. 인증은 보안 설정 또는 Vercel 연결로 제공해야 하며 채팅에 토큰 값을 쓰지 마세요.

프로덕션 배포, 정식 도메인 별칭 변경, `--prod` 실행은 사용자의 별도 승인 전까지 금지합니다. 기존 격리된 체크아웃을 사용하며 요청 없이 Git worktree를 만들지 않습니다. 검증 세부 결과는 [VALIDATION.md](VALIDATION.md)를 확인하세요.
